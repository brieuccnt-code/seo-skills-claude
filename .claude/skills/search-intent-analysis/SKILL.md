# Search Intent Analysis

## Méthode (par requête ou cluster)
1. **Tâche** : reformuler en une phrase ce que l'internaute veut accomplir.
2. **Intention** : informationnelle, commerciale (je compare), transactionnelle (j'agis), navigationnelle, locale, mixte.
3. **SERP** (si relevé disponible ou fourni) : pour le top 10, noter le type de page (article, catégorie, fiche, comparatif, outil, vidéo, forum, page locale), le format (liste, guide, tableau), la fraîcheur, et les blocs (pack local, Shopping, « Autres questions », vidéos, aperçu IA).
4. **Format dominant** : le type de page qui représente au moins 6 résultats sur 10. S'il n'y en a pas, l'intention est mixte : choisir selon l'offre et noter le risque.
5. **Sous-intentions** : questions secondaires qui doivent être traitées dans la page.
6. **Couverture actuelle** : une page du site répond-elle déjà ? Si oui, l'améliorer plutôt que créer.

## Signaux lexicaux (indices, jamais preuves)
« prix, devis, acheter, réserver » → transactionnel · « meilleur, avis, comparatif, vs » → commercial · « comment, pourquoi, qu'est-ce que » → informationnel · « près de moi, + ville » → local. La SERP prime toujours sur le mot.

## Sans accès SERP
Le dire, conclure avec une confiance « faible » et lister les requêtes à relever en priorité.

## Livrable
Tableau : cluster, tâche, intention dominante, intentions secondaires, format recommandé, éléments indispensables (blocs de contenu), CTA, page existante concernée, confiance (haute/moyenne/faible), date et pays de la SERP observée.
